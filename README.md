# WWW Project

Простой веб-проект с HTML-страницами.

## Структура проекта

```
www/
├── index.html    # Главная страница
├── page1.html    # Страница 1
└── page2.html    # Страница 2
```

## Описание файлов

- **index.html** - Главная страница сайта
- **page1.html** - Дополнительная страница 1
- **page2.html** - Дополнительная страница 2

## Использование

Откройте `index.html` в любом современном браузере для просмотра сайта.

```bash
# На Linux/Mac
xdg-open www/index.html

# На Windows
start www/index.html
```

## Технологии

- HTML5
